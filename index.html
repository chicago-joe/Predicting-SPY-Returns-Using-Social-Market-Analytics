Predicting SPY Returns Using Social Market Analytics

This project explores the use of SPY pricing data and sentiment data feed from Social Market Analytics to generate a 1D SPY forecast using comprhensive social media metrics, mathematical and regression modelling, and robust trading signals. Portfolio strategy generated a cumulative return of 70.46% from January 2018 to September 2019.
